# Week 3 Weather App

A responsive weather application built with HTML, CSS and JavaScript. It uses the OpenWeatherMap Current Weather API and the Fetch API.

## Setup

1. Create a free account at https://openweathermap.org/ and generate an API key.
2. Open `script.js`.
3. Replace `YOUR_OPENWEATHERMAP_API_KEY` with your API key.
4. Open `index.html` in your browser (or use VS Code Live Server).
5. Enter a city name and click Search.

## Assignment requirements covered

- City name input
- Fetch API request
- JSON response parsing
- Current temperature
- Humidity
- Weather condition
- Clean responsive card UI

Temperature is displayed in Celsius (`units=metric`). A valid API key and internet connection are required.
